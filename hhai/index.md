## AI HOT iOS

一个面向 iPhone 的 AI 资讯阅读客户端，内容来自 **数字生命卡兹克** 的精选 feed。专注于提供"少而精的 AI 信息流"，过滤无关噪音，保留有价值的内容。

### 特性

- 时间线浏览，支持下拉刷新与分页加载
- 离线正文缓存（Markdown），通过外部 API 转换为可读文本
- 彩色进度指示器，直观显示同步状态
- 自适应查看：优先打开本地文件，失败时回退到 WebView 在线加载
- 支持自定义 Firecrawl API Key
